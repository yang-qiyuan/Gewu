### DeepSpeed ZeRO vs. PyTorch FSDP 选型总结

| 场景 / 需求 | 推荐工具 | 核心理由 |
| :--- | :--- | :--- |
| **使用 Hugging Face Trainer** | **DeepSpeed** | 集成极度成熟，只需一个 `ds_config.json` 即可启动，生态支持最好。 |
| **显存极度受限 / 需要 Offload** | **DeepSpeed** | ZeRO-Offload 在 CPU 内存卸载方面优化更激进，适合单卡跑超大模型。 |
| **超大规模集群 (千卡级)** | **DeepSpeed** | 经过大规模实战验证（如 BLOOM, GLM 等），有 ZeRO-Infinity 等针对性优化。 |
| **手写 PyTorch Training Loop** | **FSDP** | 代码原生、Pythonic，无第三方依赖，调试堆栈清晰，完全可控。 |
| **PyTorch 2.x / 新硬件 (H100)** | **FSDP** | 官方原生支持，与 `torch.compile` 编译器配合更佳，新特性适配快。 |
| **混合切分策略 (Hybrid Sharding)**| **FSDP** | 原生支持节点内切分、节点间复制，配置直观，适合网络带宽受限的集群。 |
