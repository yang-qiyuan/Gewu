1. Offline
   - indirect method
   - dataset:
     - Reference basis vs non-reference basis
     - common cases
     - edge cases
     - adversary cases: model should refuse
     - multiturn dialogue
   - testing strategies
     - automatic evals:
       - OpenAI Eval
       - deepeval
       - llm-as-judge (could have randomness)
         - Another dataset for evaluation of llm as a judge
         - judge with human
     - human evals:
       - creativity
       - humor
       - ...
   - regression test: upgraded system should be better than previous version

2. Online
   - user preference (direct)
     - within subject: two different models, choose which better
     - between subject: A/B test, two different models for different users
     - user: dislike/like button
   - cost
   - user experience
   - observability

3. Evaluation Metrics
   - performance/quality
     - accuracy
     - fluency/conherence/relevance/task success rate
  - Reliability/Robustness
    - hallunciation: 1. citation; 2. private data; 3. change the format of the question, hallucination rate;
    - Robustness: typos introduction, and perturbation;
    - adversary attack
  - Responsiblility
    - bias, fairness
    - privacy and safety
  - Efficiency
    - latency
    - throughput
    - cost
